# Files intentionally not committed

The research session also used user-supplied Sophos/Marvell binary modules and generated full disassemblies/strings/symbol dumps for compatibility analysis.

Those files are intentionally not included here. The repository keeps only:

- independently written FreeBSD driver source
- derived protocol facts / notes
- read-only hardware captures and console logs
- collector/build scripts

This keeps the project source-focused and avoids redistributing proprietary vendor binaries.
